# CIVIS - Community Infrastructure, Visibility, and Integrated Services

CIVIS is an Android mobile application project developed for
IT114 - Mobile Development Fundamentals.

The application is designed to provide barangay residents with a
centralized way to report and monitor non-emergency community and
infrastructure issues, while allowing barangay personnel to review,
assign, inspect, and resolve reported cases.

## Current Development Phase

The project is currently in the structural UI implementation phase.

The current focus is translating the approved CIVIS prototype into
Jetpack Compose layouts using:

- Screen structure
- Column, Row, and Box layouts
- Modifier usage
- Nested composables
- Reusable UI components
- @Preview for independent screen rendering

Navigation, state-driven behavior, business logic, and data persistence
are not part of the current implementation phase.
